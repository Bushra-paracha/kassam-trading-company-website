# Kassam Trading Company Static Website

Static HTML/CSS/vanilla JavaScript website with no build step.

## Local preview
Open `index.html` directly, or run a basic local server.

## GitHub + Netlify
1. Push this folder to a GitHub repository.
2. In Netlify, choose **Add new site → Import an existing project**.
3. Select the GitHub repository.
4. Leave the build command empty and use `.` as the publish directory.
5. Deploy. Netlify will detect the form named `quote-request`.

## Before launch
- Replace SVG placeholders in `assets/images/` with verified KTC photography.
- Add verified company phone/email only after confirmation.
- Add real downloadable certificates to `assets/downloads/` and link them from the compliance page.
- Review all product specifications before publishing.
