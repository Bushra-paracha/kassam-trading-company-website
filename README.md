# Kassam Trading Company — Static Website

Lightweight, dependency-free version of the [Kassam Trading Company](https://kassamtradingcompany.com) website: plain HTML, CSS and vanilla JavaScript with no build step, deployed on Netlify.

## Pages
Home · About · Products · Certificates & Compliance · Global Presence · Gallery · News · Contact (with a Netlify-handled quote request form)

## Highlights
- Responsive layout and shared stylesheet in `assets/css/styles.css`
- Custom SVG illustrations for products and facility
- Zero-config Netlify deploy via `netlify.toml`

## Run locally
Open `ktc-static-site/index.html` in a browser, or serve the folder:

```bash
cd ktc-static-site
python3 -m http.server 8000
```
